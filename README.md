# MedTimer CLI 💊
**Autor:** Eduardo Moreira Chaves
**Versão:** 1.0.0

## 📝 Descrição do Problema
Muitas pessoas, especialmente idosos e cuidadores, enfrentam dificuldades em organizar os horários de medicamentos de uso contínuo, o que pode levar a erros de dosagem ou esquecimentos prejudiciais à saúde.

## 🚀 Proposta da Solução
O **MedTimer CLI** é uma aplicação simples e eficiente que calcula automaticamente as próximas três doses de um medicamento com base no horário inicial e no intervalo prescrito, ajudando no planejamento diário.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.13
- **Testes:** Pytest
- **Qualidade/Linting:** Flake8
